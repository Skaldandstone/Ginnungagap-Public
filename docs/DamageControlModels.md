# Damage-Control Models

`tools/build_damage_control_models.py` creates twelve damaged-state, emergency-response, and
repair-state meshes under `/Game/Assets/Models/DamageControl`.

The set supplies hull-breach open/patched states, ruptured pipes, exposed cables, damaged junctions,
pressure-leak fixtures, fire and air equipment, radiation and folding barriers, repair foam, and a
casualty bag. All assets use production environment surfacing and generated collision.

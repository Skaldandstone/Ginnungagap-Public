# Ship Exterior Detail Models

`tools/build_ship_exterior_detail_models.py` creates twelve collision-ready exterior modules under
`/Game/Assets/Ships/Exterior/Details`.

The set includes RCS clusters, high-gain antennae, armor and thermal panels, observation blisters,
lifeboats, EVA rails, service hatches, heat exchangers, defense mounts, passive sensors, and cargo
clamps. They use the shared exterior-hull production surface and can be instanced across ship LODs.

# Room Machinery Models

`tools/build_room_machinery_models.py` creates fourteen room-specific, collision-ready machinery
meshes under `/Game/Assets/Models/RoomMachinery`.

The set covers medical diagnostics and storage, reactor and power machinery, coolant and utility
systems, cargo handling, helm/navigation furniture, and drone maintenance/launch equipment. All
assets use the shared production environment surface and are scaled in Unreal centimeters.

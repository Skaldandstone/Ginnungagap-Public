# Handheld and Mission Models

`tools/build_handheld_and_mission_models.py` creates fourteen socket-ready items under
`/Game/Assets/Models/GameplayItems`. The set includes industrial weapons, EVA and repair tools,
medical supplies, replacement ship components, and mission-critical sample/data containers.

All origins and dimensions are authored in Unreal centimeters. Handhelds use the production
equipment surface; consumables and objective items use the production pickup surface.
